# Features V1

## 1. Authentication

- Email/password and Google sign-in
- Only authorized users can access data
- Ability to invite a co-parent (same household)
- Sign out

## 2. Quick Event Logging

Mobile-first interface with large buttons for fast input:

### Feeding
- Type: left breast / right breast / bottle
- Start time (pre-filled with now, editable)
- Duration (optional — built-in timer or manual input)
- Notes (optional)

### Pee
- Time (pre-filled with now, editable)
- Notes (optional)

### Poop
- Time (pre-filled with now, editable)
- Color/consistency (optional, useful for pediatrician)
- Notes (optional)

### Medication
- Medication name
- Dose
- Time (pre-filled with now, editable)
- Notes (optional)

## 3. Daily Dashboard

- Current date with day-by-day navigation (< yesterday | today | tomorrow >)
- Summary counters: number of feedings, pees, poops, medications
- Chronological timeline of the day's events
- Last event of each type with elapsed time ("last feeding 2h30 ago")

## 4. Charts and Statistics

### Weekly View
- Stacked bar chart: event count per day over 7 days
- Day-by-day comparison

### Monthly View
- Trend lines over 30 days
- Daily averages

### Filters
- By event type (feeding, pee, poop, medication)
- By custom date range

## 5. PWA

- Installable on home screen (mobile and desktop)
- Works offline (caches recent data, syncs on reconnect)
- Custom icon and splash screen
